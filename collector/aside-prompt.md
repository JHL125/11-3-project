네이버 지도(https://map.naver.com)에서 아래 장소를 검색하고, 그 구획의 좌표 정보를 JSON으로 알려줘.

- 장소 이름: {{NAME}}
- 종류: {{KIND_DESC}}

해야 할 일
1. 네이버 지도에서 "{{NAME}}"을 검색한다.
2. 종류에 맞는 좌표를 얻는다.
   - 행정구역(admin): 검색하면 지도에 그려지는 **경계 폴리곤**의 꼭짓점 좌표. 페이지가 받아 오는 경계 데이터(네트워크 응답)에서 꺼내도 된다.
   - 도로(road): 지도에 강조되는 **도로 선**의 좌표. 끊긴 구간이 있으면 구간별로 나눈다.
   - 지명(poi): 장소의 **중심 좌표** 한 점.
3. 어떤 종류든 `center`(중심 좌표)는 꼭 넣는다.

좌표 규칙
- WGS84 경도 · 위도만 쓴다. 순서는 **[경도, 위도]** 예: [127.0276, 37.4979]
- 다른 좌표계(UTM-K 등)로 받았다면 WGS84로 바꿔서 넣는다
- 추측해서 만든 좌표는 넣지 않는다. 못 구한 값은 null 로 둔다

출력 형식 — 마지막에 아래 표시 사이에 JSON 하나만 출력한다. 다른 설명은 표시 밖에 쓴다.

<<<JSON
{
  "name": "{{NAME}}",
  "kind": "{{KIND}}",
  "center": [경도, 위도],
  "polygon": {"type": "Polygon", "coordinates": [[[경도, 위도], ...]]},
  "line": [[[경도, 위도], ...]]
}
JSON>>>

- admin 이면 polygon 을 채우고 line 은 null
- road 이면 line 을 채우고 polygon 은 null
- poi 이면 polygon, line 모두 null
- 로그인 · 결제 · 글쓰기 같은 작업은 하지 않는다. 지도 검색과 읽기만 한다
